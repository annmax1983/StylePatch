StylePatch Privacy Policy

StylePatch does not collect or share personal data. Styles are applied locally and stored in your browser. If you enable Premium cloud sync, saved styles are copied through your browser account; if you choose a web font, the font file is downloaded from Google Fonts. No analytics, no account.

01Data Collection

StylePatch does not collect any of the following:

  • Personal identification information
  • Browsing history or URLs visited
  • Usage analytics or telemetry
  • Cookies or tracking identifiers
  • Form data, passwords, or credentials

02Data Storage

StylePatch stores the following data locally in your browser using the Chrome Storage API:

  • Per-site style settings — background color, text color, font size you choose for each website
  • Global preferences — extension on/off state, excluded sites list
  • Install ID — a random identifier generated for this installation, used to count license activations.
  • License data — license key and activation status, stored locally. If the server cannot be reached, the cached license keeps working until the next successful check

Local data is deleted when you uninstall the extension. If you enable Premium cloud sync, a copy of your saved site styles is also held in your browser account (see Cloud Sync below).

03Cloud Sync (Premium)

With Premium, you can turn on cloud sync. Saved site styles are then written to chrome.storage.sync, the browser's own account sync operated by Google or Microsoft. The developer operates no sync server and cannot read this data. Sync is off unless you enable it; turning it off stops future syncing but does not erase copies already in your browser account. Per-site styles are otherwise stored locally in chrome.storage.local.

04Permissions

  • storage — Required to save your style settings locally
  • scripting — Required to inject custom CSS styles into web pages
  • host_permissions (<all_urls>) — Required to apply custom CSS styles to any website you visit. StylePatch only injects CSS when you explicitly enable it for a site.

StylePatch does not use these permissions to read page content, track activity, or transmit data.

05Third-Party Services

License Verification (Premium Features): If you activate a premium license, StylePatch sends a verification request to the author's license server at api.annmax1983.com. The request includes: license key, a random install identifier, plugin identifier, and browser metadata (version, language, timezone). That server processes payments and licensing through Creem; your browser does not connect to Creem or any other third party directly. Our license server records the IP address of these requests solely for rate limiting and abuse prevention — never for profiling, advertising, or sharing with third parties.

Optional Web Fonts: If you choose a Google Font in the popup, StylePatch downloads the font file itself from fonts.googleapis.com and fonts.gstatic.com. These downloads contain no information about you or the pages you visit, and happen only while a web font is selected.

06Data retention & deletion

Your settings and content stay in your browser until you delete them in the extension or uninstall it. Uninstalling removes the extension's local data. Nothing is retained on our servers, because your content is never sent to them. If you enabled a feature that uses your browser account's sync, a copy may remain in that account. You can manage or remove it in your browser's sync settings.

07Changes to this policy

If this policy changes, the revised version will be published on this page with a new date. Material changes will be noted in the extension's release notes.
