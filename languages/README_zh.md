# StylePatch
[English](../README.md) | 中文 | [Español](README_es.md) | [Deutsch](README_de.md) | [日本語](README_ja.md) | [Français](README_fr.md)

一款轻量级浏览器扩展，可即时自定义任何网页的背景色、文字色、字体、滤镜效果和字号。

> 基于 Chromium · Manifest V3 · 无追踪 · 按站点保存设置（云同步可选，属于高级功能）

## 使用方法

1. **点击工具栏中的 StylePatch 图标**
2. **选取颜色** — 使用原生取色器或输入十六进制色值
3. **选择预设** — 亮色、暖色、绿色、暗色、护眼褐色、蓝夜或高对比度
4. **调整字号** — 拖动滑块，80% 至 150%
5. **更换字体** — 选择系统字体，或在线加载 Google 字体
6. **应用滤镜** — 可选灰度模式或暖色护眼滤镜
7. **保存** — 点击 **应用并保存**，设置将持久化到当前站点
8. **重置** — 点击 ↺ 移除当前站点配置；若设置了默认主题则回退到默认主题
9. **设为默认** — 高级用户可将当前配色保存为所有网站的默认主题（已单独配置的网站不受影响）
10. **排除** — 点击"排除此站点"加入黑名单
11. **切换** — 使用开/关按钮，禁用但不丢失设置

点击应用后设置自动保存，再次访问同一网站时自动恢复。

### 配置管理器

点击弹窗底部的 **⚙ 配置管理器** 打开配置页面：

- **查看**、搜索和**删除**已配置的站点及其颜色与字体设置
- **导出**全部配置为 JSON 备份文件（免费）
- **导入**备份文件，在新设备或重装后恢复设置（免费版最多恢复 5 个站点）
- **云端同步**（高级）— 在同一浏览器账号登录的 Chrome/Edge 配置间同步配置
- **默认主题**（高级）— 查看或移除应用于未单独配置网站的主题

## 隐私

- 仅需 `storage`、`scripting` + `host_permissions` 权限
- `storage`：在本地保存自定义颜色、字号、字体、滤镜、站点黑名单和主题偏好，不存储网页内容；可选的高级云端同步使用 `chrome.storage.sync`
- `scripting`：仅用于向当前标签页注入生成的 CSS 样式（扩展的隔离环境），不读取页面内容，也不执行远程代码
- `host_permissions`：仅用于注入自定义 CSS 样式，不读取 DOM 文本、图片、表单数据或 Cookie
- 不访问浏览历史，不追踪用户，不内置第三方分析
- 数据默认保存在本地，仅在以下情况离开浏览器：
  - 手动导出备份文件；
  - 开启云端同步（高级版）：仅将站点配置、黑名单、开关状态和默认主题存入浏览器账号，绝不同步授权密钥或浏览数据；
  - 选择 Google 在线字体时，从 fonts.googleapis.com 下载字体文件本身；
  - 激活或校验授权时，授权密钥、随机安装 ID 和基本浏览器信息会发送到 api.annmax1983.com
- [隐私政策](https://annmax1983.github.io/StylePatch/privacy-policy.html)
